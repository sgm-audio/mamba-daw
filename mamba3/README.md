# MambaDAW

CPU per-sample State Space Model (.mmbw format, Phase 1 done) and MambaCompressor research.

## Structure
- `mamba3/`: Core Mamba3 training scripts, model definitions, and inference pipelines.
- `research/mamba-compressor/`: Experimental research on Mamba-based audio compression and dynamic processing.

## Quick Start
```bash
python launch_train.py
```
